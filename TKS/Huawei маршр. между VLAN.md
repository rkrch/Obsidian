
**Топология сети**:

Компьютеры PC1 и PC2 принадлежат к разным VLAN. Для их взаимодействия необходимы интерфейсы VLANIF на S1 или подынтерфейсы Dot1Q на R1.
![[Pasted image 20260410111207.png]]

Используемое оборудование

- **Маршрутизаторы**: AR2220
- **Коммутаторы**: S5700
- **Компьютеры**: PC

**План работы**:

1. Настройка подынтерфейсов Dot1Q для реализации связи между VLAN.
2. Настройка интерфейсов VLANIF для реализации связи между VLAN.

---
### **Шаг 1. Настройте основные параметры устройств**
Присвойте устройствам имена. Настройте IP-адресацию и шлюзы на PC1 и PC2  
согласно **таблице 1**.
На S1 назначьте интерфейсы GigabitEthernet0/0/2 и GigabitEthernet0/0/3 во VLAN 2 и  
VLAN 3 соответственно.
**Таблица 1** – IP-адресация для PC

|Устройство|IP-адрес/маска|Шлюз|
|---|---|---|
|PC1|192.168.2.1/24|192.168.2.254|
|PC2|192.168.3.1/24|192.168.3.254|

---

### **Шаг 2. Настройте подынтерфейсы Dot1Q**

Настройте магистральный порт на S1.

```
[S1]interface GigabitEthernet 0/0/1
[S1-GigabitEthernet0/0/1]port link-type trunk
[S1-GigabitEthernet0/0/1]port trunk allow-pass vlan 2 3
```

Настройте подынтерфейс Dot1Q на маршрутизаторе R1.

```
[R1]interface GigabitEthernet 0/0/1.2
```

После создания подынтерфейса осуществляется переход в режим конфигурирования подынтерфейса. В этом примере цифра 2 в номере интерфейса (0/0/1.**2**) указывает номер подынтерфейса. Рекомендуется, чтобы номер подынтерфейса совпадал с идентификатором VLAN.

```
[R1-GigabitEthernet0/0/1.2]dot1q termination vid 2
[R1-GigabitEthernet0/0/1.2]ip address 192.168.2.254 24
[R1-GigabitEthernet0/0/1.2]quit
[R1]interface GigabitEthernet 0/0/1.3
[R1-GigabitEthernet0/0/1.3]dot1q termination vid 3
[R1-GigabitEthernet0/0/1.3]ip address 192.168.3.254 24
[R1-GigabitEthernet0/0/1.3]quit
```

Команда **`dot1q termination vid`** _`vlan-id`_ позволяет настраивать идентификатор VLAN для терминирования Dot1Q на подынтерфейсе.

В этом примере, когда GigabitEthernet0/0/1 получает данные с тегами VLAN 2, он передает данные на соответствующий подынтерфейс (GigabitEthernet0/0/1.**2**) для терминирования VLAN и последующей обработки. Данные, отправляемые с данного подынтерфейса, также помечаются тегами VLAN 2.

```
[R1-GigabitEthernet0/0/1.2]arp broadcast enable
[R1-GigabitEthernet0/0/1.3]arp broadcast enable
```

Подынтерфейсы, выполняющие удаление тегов VLAN, не могут пересылать широковещательные пакеты и автоматически отбрасывают их при получении. Чтобы такие подынтерфейсы могли пересылать широковещательные пакеты, необходимо выполнить команду **`arp broadcast enable`**.

Проверьте связь между устройствами их разных VLAN при помощи команды `ping`.

---

### **Шаг 3. Настройте интерфейсы VLANIF**

Удалите лишние настройки

Перед выполнением данного шага, **удалите конфигурацию**, созданную на предыдущем шаге.

Создайте интерфейс VLANIF на коммутаторе S1.

```
[S1]interface Vlanif 2
[S1-Vlanif2]ip address 192.168.2.254 24
[S1-Vlanif2]quit
[S1]interface Vlanif 3
[S1-Vlanif3]ip address 192.168.3.254 24
[S1-Vlanif3]quit
```

С помощью команды **`interface vlanif`** _`vlan-id`_ можно создать интерфейс VLANIF и перейти в режим его конфигурирования. Перед настройкой интерфейса VLANIF необходимо **создать VLAN**.
